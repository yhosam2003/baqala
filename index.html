    Your shops

    Connect GitHub to save shops

    Shops are saved to two repositories on your GitHub: the public website, and a private list of owners. Do this once on each phone you use.

    1. Create two repositories: baqala (Public, the website) and baqala-private (Private, tick “Add a README file”).
    2. Create a fine-grained token on GitHub
    3. Repository access: Only select repositories, then pick both repositories.
    4. Permissions: set Contents to Read and write.
    5. Generate the token, copy it and paste it below.
